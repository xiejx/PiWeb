How to configure a TeHyBug

Enter the following URL into your TeHyBug's configuration:

s1 / s2 (temperature + humidity):

{{ track_url }}?t=%temp%&h=%humi%&chipid=%chipid%&sensor=%sensor%

s3 (temperature + pressure):

{{ track_url }}?t=%temp%&p=%qfe%&chipid=%chipid%&sensor=%sensor%

s4 (temperature only):

{{ track_url }}?t=%temp%&chipid=%chipid%&sensor=%sensor%

s5 (temperature + humidity + pressure):

{{ track_url }}?t=%temp%&h=%humi%&p=%qfe%&chipid=%chipid%&sensor=%sensor%

The sensor value is used as the TeHyBug key when bug_key is not sent. Set a static IP for your Raspberry Pi in your router to keep the URL stable.
